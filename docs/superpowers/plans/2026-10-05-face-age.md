# Face age implementation plan

**Goal:** implement proposal as a reproducible research program, with an empty individual logbook.

**Architecture:** Python package for data and experiments; shared checkpoint inference in CLI and Streamlit. Files remain in the repository requested by the user. Existing proposal files are preserved.

**Tech stack:** Python 3.10+, PyTorch, torchvision, Pillow, NumPy, Matplotlib, Streamlit, pytest.

**Spec:** `docs/superpowers/specs/2026-10-05-face-age-design.md`.

## Global constraints

Age 0-116; grouped 70/15/15 split; seed 42; no fabricated research results; no stored uploads; empty logbook; pretrained default for research and explicitly untrained weights for smoke only.

## Review focus

Duplicate images renamed or encoded differently; tiny/sparse datasets; mismatched checkpoints/manifests; malformed images; lack of internet/GPU/checkpoint. Tests exercise these boundaries.

## Tasks

1. Data audit and fixed manifest (`faceage/data.py`): RED tests for invalid filenames, corrupt images, duplicate leakage, deterministic splits, unsafe paths. Implement and run data suite.
2. Training/evaluation (`faceage/model.py`, `training.py`, `evaluation.py`, `metrics.py`): RED tests for known metrics, empty/nonfinite predictions, frozen BatchNorm, trainable final blocks, checkpoint metadata. Implement B0/B1/M1/B1-control and run suite.
3. Interfaces (`faceage/cli.py`, `app.py`): test real prepare/train/evaluate/compare/predict path on synthetic fixtures, refusal of mismatched data and fake demo models. Implement and run integration tests.
4. Documentation/configuration and blank tracking templates: README, configs, references, contribution and checkpoint templates, blank CSV/Markdown logbook. Run full suite, CLI smoke test, Streamlit health and UI checks. Record evidence, preserve synthetic distinction.

Execution is performed in this session as requested by the user; no separate design approval is requested because the proposal already supplies the approved implementation scope. No remote publishing, commit, or push is performed implicitly.
